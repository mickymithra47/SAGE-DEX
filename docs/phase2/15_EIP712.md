# 15 — EIP-712: Typed Structured Data Hashing & Domain Separators

## 1. What is EIP-712?
**EIP-712** is the Ethereum standard for hashing and signing structured, typed data. Before EIP-712, users signed opaque hex blobs (`eth_sign`), enabling phishing contracts to trick users into signing malicious transactions.

---

## 2. The 3 Core Components of EIP-712

### 1. Domain Separator
Binds the signature to a specific protocol name, version, chain ID, and contract address:

```solidity
DOMAIN_SEPARATOR = keccak256(
    abi.encode(
        keccak256("EIP712Domain(string name,string version,uint256 chainId,address verifyingContract)"),
        keccak256(bytes("Sage Permit Token")),
        keccak256(bytes("1")),
        block.chainid,
        address(this)
    )
);
```

### 2. TypeHash & StructHash
Encodes the exact schema and parameter values:
$$\text{structHash} = \text{keccak256}(\text{abi.encode}(\text{TYPEHASH}, \text{param}_1, \text{param}_2, \dots))$$

### 3. Canonical Final Digest
$$\text{Digest} = \text{keccak256}(\text{0x1901} \parallel \text{DOMAIN\_SEPARATOR} \parallel \text{structHash})$$
- `0x1901`: Prefix defined by EIP-191 to ensure structured messages never collide with valid RLP-encoded Ethereum transactions.
