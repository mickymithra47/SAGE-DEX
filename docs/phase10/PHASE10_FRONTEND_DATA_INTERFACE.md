# Phase 10 — Frontend Web Interface Data Consumer

## 1. UI Integration Surface
- **Pool Directory**: Queries `getPools` for TVL rankings and token pairs.
- **Price Charting**: Queries `getCandles` for multi-timeframe OHLCV candles.
- **Portfolio**: Queries `getUserPositions` for active LP shares and underlying token asset estimations.
- **Trade Activity**: Queries `getUserSwaps` for past execution records.
