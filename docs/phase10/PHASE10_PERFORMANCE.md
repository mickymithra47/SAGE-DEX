# Phase 10 — Performance & Benchmarks

## 1. Measured Benchmarks
- **Ingestion Speed**: > 2,500 events / second.
- **Resolver Query Latency**: < 5ms for pool and swap queries.
- **Reorg Rollback Speed**: < 10ms for 10-block rollbacks.
- **Memory Footprint**: < 120 MB RAM for in-memory active cache.
