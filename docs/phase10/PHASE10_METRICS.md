# Phase 10 — Quantitative Metrics Catalog

## 1. Metrics Definitions
- `blocks_processed_total`: Cumulative counter of blocks ingested.
- `events_processed_total`: Cumulative counter of decoded logs.
- `indexer_lag_blocks`: Current block distance behind chain head.
- `rpc_errors_total`: Count of RPC connectivity faults.
- `reorgs_total`: Count of detected chain reorganizations.
- `reconciliation_failures_total`: Divergences detected by reconciliation.
