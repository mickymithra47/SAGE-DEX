# 35 — Liquidity Management UI & LP Share Quoting

## 1. Liquidity Features
- **Add Liquidity**: Proportional calculation of second token input based on current pool reserve ratio ($R_0 / R_1$).
- **Remove Liquidity**: Percentage-based redemption ($25\%, 50\%, 75\%, 100\%$) displaying expected underlying tokens.
- **LP Position Card**: Displays active LP token balance and ownership share of pool.
