# SAGE Security Documentation

This directory contains security documentation, threat models, attack lab analyses, and invariant verifications for SAGE DEX.

## Overview
- **Threat Modeling**: Protocol trust boundaries, adversarial attack vectors, and privilege boundaries.
- **Contract Security**: Reentrancy protection, callback safety, and arithmetic overflow guarantees.
- **Signature Security**: EIP-712 & EIP-2612 permit validation and replay attack mitigation.
- **Audit Reports**: Detailed audit findings are cataloged in [`docs/audits/`](../audits/).
- **Phase Verification**: Phase-specific security reports and checklists are located in [`docs/phases/`](../phases/).
