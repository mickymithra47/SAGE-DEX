# SAGE Protocol Development Phases

This directory contains specifications, security audits, checklists, and reports corresponding to protocol development phases.

- **Phases 2-10**: Modular phase specifications are maintained in their respective directories:
  - [`docs/phase2/`](../phase2/) — Multi-chain token & network configuration
  - [`docs/phase3/`](../phase3/) — AMM Core & factory/pair mechanics
  - [`docs/phase4/`](../phase4/) — Liquidity position & LP accounting
  - [`docs/phase5/`](../phase5/) — Oracle & pricing engine
  - [`docs/phase6/`](../phase6/) — Swap router & multi-hop execution
  - [`docs/phase7/`](../phase7/) — Permit2 & authorization architecture
  - [`docs/phase8/`](../phase8/) — Frontend architecture
  - [`docs/phase9/`](../phase9/) — Indexer & database architecture
  - [`docs/phase10/`](../phase10/) — Observability, metrics & reconciliation
- **Phase 10-12 Documents**: Located directly in this folder:
  - Phase 10 reports and audit files (`PHASE10_*`)
  - Phase 11 comprehensive security and threat model audits (`PHASE11_*`)
  - Phase 12 deployment runbooks and configurations (`PHASE12_*`)
  - [`SAGE_PHASE2.md`](./SAGE_PHASE2.md)
