# 05 — EIP-2612 Gasless Permit Architecture

## 1. Permit Mechanics
```solidity
function permit(
    address owner,
    address spender,
    uint256 value,
    uint256 deadline,
    uint8 v,
    bytes32 r,
    bytes32 s
) external;
```

---

## 2. Signature Elements
- **Owner**: Signer granting authorization.
- **Spender**: Authorized spender address.
- **Value**: Authorized token amount.
- **Nonce**: Sequential replay protection counter (`nonces[owner]++`).
- **Deadline**: Expiration timestamp (`block.timestamp <= deadline`).
- **Domain Separator**: Cryptographically binds signature to chain ID and token contract address.
